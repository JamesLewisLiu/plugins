# GuitarFreaks / DrumMania XG2 local server

Local server plugin for K32 DrumMania XG2 and K33 GuitarFreaks XG2.

## Features

- Card registration and player profiles.
- Separate K32 and K33 save data.
- Standard and Classic scores, Skill data, and player progress.
- Groups, events, trials, rankings, and cabinet registration.
- A profile WebUI for viewing records and Skill data, changing the player name and default mode, and updating the Group icon when permitted.

Scores and Skill data in the WebUI are read-only.
